ISO prototipe UEFI ARM64

amba-linux-0.1.0.iso

siap

ISO 9660 + El Torito UEFI (Rock Ridge/Joliet) yang memuat kerangka boot: stub BOOTAA64.EFI/BOOTX64.EFI, konfigurasi systemd-boot dan GRUB, profil distro, skrip build, serta dokumentasi. Belum memuat kernel, initramfs, rootfs, atau KDE Plasma, sehingga belum bisa boot ke desktop — media inspeksi kerangka boot, bukan sistem lengkap. Berkas ini dicerminkan di repositori (releases/) karena aset rilis belum diunggah.

Ukuran
± 1,6 MB
Kebutuhan
QEMU ARM64 UEFI (virt) atau perangkat ARM64 UEFI; pycdlib untuk membangun ulang
Jenis
ISO
  1. UnduhKlik tombol di bawah; berkas tersimpan di folder Download perangkat.
  2. VerifikasiBandingkan SHA-256 dengan SHA256SUMS sebelum dipakai.
  3. PakaiKlik Unduh untuk mengambil berkas dari cermin repositori, lalu verifikasi SHA-256. Tulis ke USB dengan dd/balenaEtcher hanya untuk memeriksa kerangka boot. Sistem lengkap dibangun di host Arch Linux ARM aarch64 (docs/BUILD.md).

Memasang APK di Android

  1. Unduh amba-android-0.1.0.apk Berkas ada di kartu “Android (APK)” di atas, atau di halaman rilis GitHub.
  2. Izinkan sumber tidak dikenal Android akan menampilkan dialog; aktifkan izin hanya untuk aplikasi unduhan/browser yang dipakai.
  3. Verifikasi checksum (opsional, disarankan) sha256sum amba-android-0.1.0.apk di Linux, shasum -a 256 amba-android-0.1.0.apk di macOS, atau certutil -hashfile amba-android-0.1.0.apk SHA256 di Windows.
  4. Pasang dan buka Aplikasi menampilkan status rilis, daftar aset, dan catatan; tidak meminta izin jaringan.
APK ditandatangani kunci debug (CN=Amba Linux Release) agar bisa dipasang tanpa Play Store. Play Protect dapat menampilkan peringatan untuk aplikasi di luar toko resmi.
